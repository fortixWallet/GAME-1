# ART_BRIEF — шаблон ТЗ на арт (людині чи моделі, 04.08)

Вимоги однакові, кому б не замовляли: 2D-дизайнеру, Gemini, Meshy. Різниця
лише в тому, ХТО тримає камеру: моделі — референс-кадр (правило 19), людині —
лінійна основа (один рисунок ракурсу, з якого малюються всі стани).

## Шаблон замовлення (заповнити всі поля)

```
ПРЕДМЕТ: <що це і з якої справи; яке питання справи він несе (правило 23)>
ФАКТИ НА НЬОМУ: <список shown_in-фактів: що САМЕ має читатись оком (правило 22),
  на якому кадрі, і чи потрібен HD 2x для лупи>
ЧАСТИНИ (правило 18): корпус + кожна рухома/знімна деталь ОКРЕМО
  (шар PSD або PNG на прозорому тлі): <перелік>
СТАНИ: <closed / open / деталь знята / перевернуто / …> — УСІ з одного ракурсу
ФОРМАТ: плити предмета 1200×896 (4:3) · сцени кабінету 2752×1536 (16:9) ·
  PNG; робочі PSD із шарами зберігати і здавати
СТИЛЬ: якір — art/case_desk.png (додати до замовлення); світ і предмети —
  кінематографічна реалістика; папери/UI — гравюра XIX ст.;
  палітра: оксблад + латунь + слонова кістка; сургучевий червоний — ЄДИНИЙ акцент
ПОСАДКА: предмет у кадрі з тінню і контактом з поверхнею — не плоска наліпка
ЗАБОРОНЕНО: будь-який текст/цифри в арті (написи — шрифтом поверх) ·
  упізнавані обличчя й бренди (IP, правило 4) · окультність (ми бюро, не лавка)
```

## Приймання (без цього арт не в грі)

1. `tools/check_frames.py`: стани одного предмета — збіг ≥0.3, dx=dy≈0.
2. Деталі фактів читаються на 100% зумі; для лупи — HD-версія 2x.
3. Шви шарів невидимі при накладанні; деталь у гнізді збігається з «дірою».
4. Око: кадр поруч із case_desk.png — одна гра чи дві різні?
5. Казуал-агент кліками добуває всі факти предмета (правило 13).

## Промпт-дисципліна для генерації (наші граблі, вже оплачено)

- Стани — генерацією з попереднього кадру як референсом; слова про камеру
  (closer/macro/zoom/move the camera) ЗАБОРОНЕНІ → новий кадр = чужа зйомка.
- Наближення — тільки кропом майстер-кадру.
- Пропорція генерації = пропорція референса (4:3 на 16:9 = перекадровка).
- «No text anywhere» — у кожен промпт (кирилицю модель псує).
- «Everything else stays exactly as it is» — у кожен промпт стану.

## Коли кликати людину замість моделі (замір, не смак)

Модель провалює предмет, якщо після 3 спроб: деталі не збігаються з гніздами,
стани пливуть (<0.3), або фактурна деталь факту не читається. Тоді предмет
замовляється людині ЦИМ ЖЕ шаблоном + до нього: розшарований PSD обов'язковий,
кожна рухома деталь своїм шаром, стани — окремими артбордами з одної основи.
