# DESIGN — «Бюро атрибуції» (робоча назва)
Dark academia + дедукція, ~1900-ті. Затверджено 21–22.07.2026.

## Ідея
Гравець успадкував Бюро атрибуції: кожна річ — детективна справа, вирок — АТЕСТАТ (походження / справжність / особлива примітка) пером; печатка + сургуч — пік петлі. Відповіді — вибір з відкритих у справі варіантів (патерн Golden Idol). Емоція гри: «мій висновок має вагу».

## Правила «кожен — Шерлок»
1. Відповідь складається з відкритих карток, не з повітря.
2. ≥3 незалежні дороги до кожного висновку.
3. Підказки тільки діегетичні (кіт, лист, «читачка») — кнопки «підказка» нема.
4. Одна загадка = один стрибок думки; складання ланок гра робить видимим (теки на столі).
5. Помилка = подія з наслідком, ніколи не стіна і не екран «неправильно».
6. Три глибини правди: поверхнева (прямо, всім) / середня (з тек, більшості) / глибока (недоведена — для форумів).

## 7 типів справ (день = 3–4 різних)
1. **Клейма** — «Срібний келих»: клеймо перебите двічі → косе світло → монограма «Св. О.» → газета: пограбування ризниці → КРАДЕНА.
2. **Прохання-пошук** — «Ліки від безсоння»: слова клієнтки + довідник повір'їв + стара справа попередника → річ на власній полиці.
3. **Річ-механізм** («У РУКАХ», 3D) — «Секретер»: гравіювання + фреска + довідник орнаментів → кільця 3·1·7 → подвійне дно з листом.
4. **Шифр-лист** — підкреслені слова → «ПОЛИЦЯ IV ГЕРБАРІЙ 112» → гербарій на полиці бюро → адреса.
5. **Два свідчення** — «Спадок удови»: потертості під шульгу проти свіжих подряпин — річ сама викриває брехуна.
6. **Проти авторитета** — слід гвинтової стяжки 1840-х проти атестата професора «XVI ст.»; ставка — репутація.
7. **«Не підлягає атрибуції»** (жах, ≤1/день) — факти фізично не сходяться: архівна тріщина через ІНШЕ око.

## Сюжет «ПЕЧАТКА» (прихована правда)
Зло не в речах — у ПЕРЕДАЧІ. Печатка = двері; бюро 70 років було механізмом. Продавець приходить із різними обличчями — рука завжди одна (потертість під лівий великий палець, той самий кут). Попередник зрозумів і ПЕРЕСТАВ ставити печатки — бюро вмирало з голоду, він «зник». Три холодні хвилі — усі висновки гравця, не текст: «власники вмирали» → «ця річ стояла тут увесь час» → «дверима був я» (свій лічильник печаток).

## 7 днів / 3 акти (~19 справ + резервні слоти; день 35–45 хв)
- **Д1 (Ремесло):** пролог-навчання; келих; безсоння; тека №1 — найпростіша справа гри (чому ВІН не закрив?), усередині ескіз столу → секрет 1: потайна шухляда, його лупа. Вечір: хтось посвітив у вікно.
- **Д2:** удова; секретер (лист-натяк на мета-сюжет); коротка підробка-гумор.
- **Д3 (Патерн):** тека №2 — продано 3.03, некролог 9.03 «раптово, у 31»; професор; побутова. Вечір: перша «неможлива» річ.
- **Д4:** тека №3 — «постаріла за одну зиму», некролог «о четвертій, за сім хвилин до…», ШПИЛЬКА лишається гравцю; шифр-лист; секрет 2: годинник, що стояв на 4:07 → виставити стрілки → ключик; секрет 3: іржавий ключик змастити власною олійницею.
- **Д5:** тека №4 — «Р. Гнатюк»/«Р. Гнат», один почерк, одна рука. **Сцена-підпис:** гравець сам розкладає теки → патерн продаж→смерть → виводить РІК першого продажу. Драбина: гостя-«читачка». Секрет 4: картотека ключиком → теки 5–7 на день раніше. Вечір: постать біля вікна ближче.
- **Д6 (Печатка):** тека №5 — смерть пізніша за похорон; тека №6 порожня («Річ №6 я не наважився описати. Вона досі в будинку») → звірка полиць з інвентарною книгою → річ №6 стояла тут з дня 1. Секрет 5: кривий портрет → трикутна щілина ← шпилька. Секрет 6: сейф, код = виведений гравцем РІК (запасна дорога: рік у щоденнику) → головний атестат, заповнений до графи печатки. Ніч: річ №6 «Не для світла» → загасити лампу → у темряві відчиняється сама.
- **Д7:** тека №7 щоденник: «Печатка — це двері. Я перестав. Скільки печаток ти поставив цього тижня?» → фінальна справа: буденний чоловік, та сама потертість, він сидить навпроти → ГОЛОВНИЙ АТЕСТАТ → кінцівка.

## Механічний шар: кабінет — восьмий артефакт
Три рівні: схованки в речах клієнтів · предмет-ключ до предмета (шпилька→портрет; момент «ЦЕ ж пасує ТУДИ») · сам кабінет = найбільший артефакт попередника (7 секретів вище). Правила: фізична логіка видима оком (трикутна щілина → шукай трикутне; «не для світла» → погаси); механіка гейтить темп і бонуси, НІКОЛИ сюжет; один механізм = один ключ; руки чергуються з головою всередині дня.

## Кінцівки (мовчазні лічильники: Чесність / Цікавість / Борг)
Атрибутор (розкрив і оприлюднив) · Хранитель (розкрив і поховав) · Колекціонер (лишав «неможливе» собі — речі шепочуть твоїм голосом) · Шарлатан (брехав за гроші) · Вигнаний (борг) · Секретна (0 помилок за гру → попередник приходить сам. Живий. З одним питанням).

## Дофамінова петля
60–90 с: факт або мікрорішення («клац»-збіг у довіднику). Справа 5–8 хв: зачіпки → гіпотеза → атестат (пік: печатка) → наслідок; раз на 2–3 справи — «хвіст». День: 3–4 справи + мета-крок + вечір-клівхенгер. Гра: щоденник → головний атестат → 1 із 6 кінцівок. Реграбельність: оцінка справ («бездоганно/зі скрипом») + секретна кінцівка.

## Хронометраж
Середній гравець 5–6 год; швидкий 3.5–4; ретельний 7–8; платина із секретною ~9–11. Жанрова норма (SA 6–8).

## Якість
Казуальний агент-плейтестер проходить КОЖНУ справу без застрягання >5 хв і без зовнішньої допомоги — інакше справа переробляється. Перевірка реальними кліками.

## Гейти виробництва (по черзі, кожен через «так» Віктора)
1. Паспорт гри: аспект/роздільність, список екранів, склад головного кадру (годинник, портрет, лампа, картотека, полиці з річчю №6, вікно, двері, стіл), шрифт з українською.
2. Еталон-кадр кабінету → «оце воно» → заморозка style.py.
3. Карта розшарування (кожен екран: шари, стани, анімації).
4. Арт-макети всіх екранів картинками.
5. Вертикальний зріз «Срібний келих» — від дзвінка дверей до печатки, нуль тимчасової графіки.
6. Продакшн колоди справ → плейтести → Steam-сторінка.
