# РЕЖИСУРА І МОНТАЖ — постановка
### 25.07.2026. Тривалості в секундах, у дужках — кадри при 24 fps (реалізація: тривалість твіна).

## ГОЛОВНИЙ ЗАКОН (з нього виводиться все)

> **Різкий стик = дія гравця. Мікшування = плин часу в тій самій рамці.
> Затемнення = наслідок, якого гравець не бачив.**

Три інструменти, три значення. Змішаєш — мова розсиплеться.

## 1. МОВА КАДРУ

Шкала планів = **шкала влади гравця**. Ширше — менше може. Ближче — більше.

| Сцена | План | Чому |
|---|---|---|
| Меню (двері знадвору) | загальний, людина мала | він ще не всередині, він проситься |
| **Кабінет (HUB)** | загальний з висоти 1.6 м | майстер-шот. **Одна камера на кімнату, ніколи не змінюється** |
| Клієнт | середній, поясний | **крупного плану обличчя гра не дає** |
| Стіл | середньо-загальний, 35–40° згори | план рук |
| Річ у руках | деталь, річ на 60% кадру | |
| Лупа / клеймо | **макро** | єдиний макро в грі — тому й працює |
| Атестат | середній згори, **краї столу видно** | інверсія: це документ у світі, не інтерфейс |
| Гросбух | середній, сторінка **обрізана краєм кадру** | обрізаний кадр = «це більше за тебе» |
| Ранок | загальний, **ЗОВНІ бюро**, холодніший грейд | єдине вікно у світ |

**Крупний план обличчя — рівно ДВІЧІ за 8 годин:** справа 8 (клієнтка келиха в коридорі,
не дивиться) і справа 9 (власник бінокля сміється з газети зі своїм ім'ям).
Витратиш раніше «просто так» — обидві сцени нічого не варті.

### Де порушувати, щоб було страшно
- **Макро без лупи** — один раз, справа 10, 1.2 с: камера підійшла сама.
- **Загальний там, де чекають деталь** — справа 7: гравець тягне восьму теку, а камера
  **від'їжджає ширше за майстер-шот**, з'являється стеля. Гравець фізично став меншим.
- **Перетин осі** — двічі: справа 10 і фінал. Має відчутись неправильно тілом.
- **Просідання висоти камери:** 1.60 м (справи 1–5) → 1.52 (6–9) → 1.42 (10–11).
  Поодинці непомітно, разом = «кімната виросла».

## 2. ПЕРЕХОДИ (тип · тривалість · правило)

| Перехід | Тип | Трив. | Суть |
|---|---|---|---|
| **Меню → Кабінет** | match cut + L-cut | 2 к (0.08 с) | ambient стартує ще на дверях (−0.40 с). Match: замкова щілина → **лампа в тій самій точці екрана**. Око ріже по яскравості. **Фейду не бути ніколи** — це та сама секунда з іншого боку дверей |
| **Кабінет → Клієнтка** | **J-cut + витримка** | 0.60 с | дзвінок — картинка НЕ міняється 14 кадрів. Це реакція простору. *Зараз у коді `_play("door_bell"); _show("CLIENT")` одним рядком — весь ефект утрачено* |
| **Клієнтка → Стіл** | cut on action | — | 1.0 с тиші після її репліки, `goblet_set` починається ще на її кадрі, стик у момент контакту скла з деревом |
| **Стіл → Річ у руках** | match cut по силуету | 4 к (0.18 с) | перший кадр HANDS = останній кадр DESK ×140%, річ **у тій самій точці й під тим самим кутом** |
| **Річ → Лупа** | **стику немає** | 0.35 с | лупа фізично входить у кадр знизу-праворуч. Єдиний спосіб дістати макро — принести його рукою |
| **→ Папери** | wipe аркушем | 0.28 с / назад 0.22 с | зворотний рух завжди коротший на 20% |
| **Стіл → Атестат** | **пан по стільниці, без стику** | 0.9 с | річ виходить ліворуч, бювар входить праворуч. *Різати не можна: інакше «дослідження» і «писанина» розділяються, і печатка нічого не важить* |
| **Печатка → Ранок** | fade + **витримка на чорному** | 1.4 + 0.8 + **1.6** + 1.0 | **довжина чорноти = кількість минулого часу.** Ніч 1.6 с · тиждень 2.6 с · сорок років 4.0 с і повна тиша |
| **Ранок → Вечір** | dissolve по тій самій рамці | росте: 0.6 → 1.0 → 2.2 с | єдиний перехід, де кадр не міняється — міняється світло. **Дні довшають на монтажі** |
| **Вечір → Гросбух** | cut on action, тілт вниз | 0.5 с | ambient продовжується без зміни — гравець нікуди не пішов |
| **Ніч → Наступний ранок** | fade + чорнота | 1.0 + 1.2 с | **у чорноті — дзвінок наступного клієнта.** Гравець прокидається від дзвінка так само, як персонаж |
| **F1 / вибір сцени** | жорсткий cut, без звуку | 0 | службовий режим мусить відчуватись службовим |

## 4. ПРАВИЛО 180° І ГЕОГРАФІЯ

**Вісь дії — лінія двері ↔ стіл, зліва направо.** Камера завжди по один її бік.

1. **Вхід завжди зліва.** Гравець рухається вправо (вглиб роботи), повертається вліво (до людей).
2. **Клієнтка — ліва третина, дивиться екранно ВПРАВО.** Жодного разу навпаки за 11 справ.
3. **Вікно = центр, точка нуль.** Тому **кнопка «назад» веде на майстер-шот**, а не «на попередній екран».
4. **Напрямок тіні — головна підказка орієнтації.** Вдень світло зліва (вікно), ввечері справа (лампа).
5. **Дозволених перетинів осі — два за гру.**

### Технічний важіль: рівні глибини в `_show()`
```
HUB=0  CLIENT=0  DESK=1  CERT=1  HANDS=2  DOCS/NEWS/CATALOG=2  LOUPE=3
```
Тип переходу — за різницею рівнів: **+1** наїзд/wipe (0.28 с) · **−1** зворотний (0.22 с) ·
**0** dissolve · **|Δ|>1 ЗАБОРОНЕНО**, потрібен проміжний кадр.
З макро не можна вискочити в кімнату: макро → деталь → стіл → кімната.
**Одна таблиця в одній функції закриває 80% монтажу гри.**

### П'ять важелів утоми дня (жодного тексту)
1. **Довшають стики:** ранок 0.4 с → вечір 1.2 с.
2. **Довшають кадри:** середня довжина плану +35% до вечора.
3. **Падає крупність:** ввечері та сама річ коштує двох кліків замість одного.
4. **Збіднюється звук:** вранці вулиця+годинник+лампа → вночі лише лампа.
   *(`ambient_bureau.mp3` розрізати на 3 шари.)*
5. **Тьмяніє картинка:** кожен перехід у межах дня −3–4% `modulate`. За день −20%, непомітно.

## 6. ТРИ КЛЮЧОВІ СЦЕНИ

### А. ПЕЧАТКА — 14 кадрів, ~11.5 с
*(зараз `_verdict_anim()` = 1.54 с: технічно чисто, драматургічно порожньо — нема очікування і нема наслідку)*

1. Атестат цілком — 1.6 с · 2. Порожній медальйон, наїзд 3% — 1.0 с · 3. Рука бере штамп — 0.6 с ·
**4. Реакція: клієнтка, не дивиться — 1.2 с, ТИША** · 5. Свічка й віск — 0.8 с ·
**6. Макро: віск падає — 0.9 с** · 7. Штамп заносять — 0.5 с ·
**8. ПАУЗА на занесеному штампі — 1.1 с, абсолютна тиша** ← тут жива кнопка «повернути без атестата» ·
**9. Удар — 0.14 с (3 кадри)** · **10. Чорний кадр — 0.08 с (2 кадри)** замість тряски ·
11. Печатка в папері — 0.7 с · 12. Штамп знімається, сургуч тягнеться — 0.5 с ·
**13. Атестат із печаткою — 2.4 с**, ambient повертається **вже не той самий** ·
**14. Картотека приймає картку — 2.2 с.** Не скорочувати ніколи.

> **Перед ударом — тиша, після удару — найдовший план.** Акцент робиться контрастом
> тривалості, не гучністю. Два кадри чорноти замість shake: око саме добудує силу удару.

### Б. РОЗКЛАДКА СЕМИ ТЕК (справа 7)
Порожній стіл 1.4 с → **сім тек по 0.55 с, рівними інтервалами як метроном** (жодного акценту) →
загальний 2.0 с → чотири вставки дат по 0.4 с → тека поза патерном 1.2 с →
*гравець тягне восьму — свою* → **музика обривається на середині такту** →
власний почерк 1.6 с у тиші → **від'їзд ширше за майстер-шот, з'являється стеля** (1.0 с) →
**тримати найширший 4.0 с**, на третій секунді один удар годинника →
стик на **порожнє гніздо для штампа** 1.0 с.

> Тут порушується все: сім однакових кадрів поспіль, від'їзд навпаки правилу крупності,
> чотирисекундна пауза. **Працює саме тому, що шість годин до цього монтаж був бездоганний.**

### В. ШТАМП У ГНІЗДО (фінал)
**Щовечірня версія — 4.2 с, незмінна, ×10:**
шухляда 0.9 → порожнє гніздо 0.7 → рука кладе штамп 1.0 (**м'який глухий стук**) →
гніздо зі штампом 0.8 → шухляда зачиняється 0.8 → cut to black 0.6.

**Фінал змінює РІВНО ТРИ речі: рамку, матеріал звуку і те, що йде після.**
Головний атестат 2.0 с (рік — його власний) → буденний чоловік 1.5 с →
релікварій **дзеркально, метал замість дерева** 0.9 с → **порожнє гніздо 0.7 с — кадр
ідентичний вечірньому** → **ПАУЗА 2.2 с** (кнопка «повернути» жива) →
рука кладе штамп 1.0 с — **той самий глухий стук, єдиний звук, який не змінили** →
гніздо 0.8 → релікварій зачиняється 0.8 →
**стара печатка на релікварії, сургуч потрісканий, сорок років — 3.0 с, наїзд 6%, тиша навіть без годинника** →
fade 2.0 с → **чорнота 4.0 с**, на 3.2 с один удар годинника.

> Фінал **не має права додавати нових прийомів**. Тільки повторити знайоме дзеркально.

## 7. ЧОГО НЕ РОБИТИ

1. **Не мікшувати між різними місцями** — крос-фейд кабінет↔стіл це телесеріал.
2. **Не фейдити через чорне на кожному переході** — кожне затемнення каже «минув час».
3. **Не різати на паузі** — стик на нерухомому кадрі завжди видно.
4. **Не витрачати крупний план обличчя.**
5. **Ніякого shake і handheld** — бюро це установа, камера на штативі, бо так стоїть влада.
6. **Ніяких музичних стингів на відкриттях** — музика **зупиняється**.
7. **Не скорочувати нудні кадри.** Перший плейтест скаже «затягнуто» — **не слухати**:
   на цьому побудовані всі три головні моменти гри.
8. **Не давати скіпати повторюване.** Милосердя = −10% за повтор, підлога 1.4 с, **ніколи до нуля**.
9. **Не міняти точку зйомки кабінету.**
10. **Не анімувати переходи інтерфейсом** — усе, що рухається, мусить бути предметом.
11. **Не ставити повний перехід на кожен клік** — 3-й раз ×0.5, 5-й зникає.
12. **Не давати ранок у тій самій крупності, що й справу.**
13. **Прибрати «CASE CLOSED»** у нинішньому вигляді (Label, rotation −9°, підскок TRANS_BACK) —
    єдине місце, що говорить мовою аркади. Або мальований відтиск, або нічого.

## 8. КУДИ ЦЕ ВСТАВЛЯТИ В КОД

Уся мова монтажу проходить через **один вузол — `_show()`**. Мінімальна робота:
- **таблиця рівнів глибини** + вибір типу переходу за різницею;
- **шар `await _transition(from, to, kind)`** над `_show()`: dissolve / wipe-аркушем / fade+hold / cut-on-sound;
- **розділити `_play()` і `_show()` у часі** — J/L-cut неможливий, поки вони в одному рядку;
- **`_show_morning()`** — текстову картку замінити на кадр зовні бюро;
- **`_verdict_anim()`** — розширити з 1.54 с до 11.5 с (найважливіше: пауза №8 і довгий кадр №13);
- **`ambient_bureau.mp3`** розрізати на 3 шари (вулиця / годинник / лампа);
- **стрілки годинника окремим спрайтом** — це не косметика, це монтажний метроном.
