## НАВИЧКИ / РЕЦЕПТИ (нове цієї сесії)

### Шрифти (важливо)
fontsource woff2-субсети РОЗДІЛЬНІ: «cyrillic» субсет БЕЗ пунктуації (крапка/тире/кома = «тофу»). ФІКС: конвертувати cyrillic+latin+latin-ext woff2→ttf і ЗЛИТИ через `fontTools.merge.Merger` у повний TTF. GitHub/GoogleFonts проксі-403 → брати через npm `@fontsource/*` (woff2). Готові merged TTF уже в проєкті.

### Папери (газети/довідники/листи) — «ідеальна» верстка
НЕ лишати колонки «смужками» і НЕ підкладати текст на окремий фон (видно шов). Правильно: генерувати ЧИСТУ поверхню (порожній папір, без ліній) + гравюру окремим вирізаним елементом (біле→альфа), а ВЕСЬ текст і структуру (шапка, колонки, filler-статті) класти шрифтом кодом. Justify-верстка в PIL: `compose_newspaper.py` — робочий шаблон (3 колонки, реальні тематичні статті-філлери, врізана гравюра). Каталог: центр емблеми знаходити детекцією (`scipy.ndimage.label`, `compose_catalog.py`), кільце — по центроїду.

### 3D (Meshy → Godot рендер)
Концепт (чиста річ, плоский сірий фон, рівне світло, вся в кадрі) → image_to_3d (remove_lighting, meshy-6) → gltf-transform optimize --compress false (для гри 2048; для малого білда 1024 webp). Рендер/прев'ю: Godot 4.7 headless, gl_compatibility, ProceduralSky (щоб срібло мало відбиття), ключ ТЕПЛИЙ + обвід ХОЛОДНИЙ + фронт-філ, FILMIC expo~1.35, turntable pivot.rotation.y. Тепле світло робить срібло латунню → холодніший обвід. Дрібні КЛЕЙМА Meshy не ліпить читабельно → клеймо = окремий 2D-оверлей під лупою.

### Godot-зріз (архітектура + граблі)
Код лише рухає арт: TextureRect(фон)+Label(шрифт-текст)+Button(flat, alpha 0 — хотспоти). Warnings-as-errors: текстуру зі словника кастувати `var t: Texture2D = tex[..]` (Variant.get_width ламає інференс). TextureRect масштаб: папір робити full-rect ЧАЙЛДОМ Control-root з явним size (сиблінг із size рендерився завеликим). Прозорі вирізи seal_cut/stamp_top_cut (інакше білий квадрат при tween). Анімація печатки: віск ллється (seal_cut проявляється/росте в центрі медальйона) → штамп stamp_top (прес-згори) б'є ПЛАСКО в центр → притиск → «CASE CLOSED». Оберт 3D — drag у `_unhandled_input`. Атестат-вибір: варіанти як flat-Button зі шрифтом під графою; клік пише на лінію.
Зйомка відео: софт-GL readback get_image() БЛОКУЄ потік → real-time waits дають нерівне відео; робити ПОКАДРОВО (_cap = await frame_post_draw + save_png; _hold(n)); кадри писати ПОЗА проєктом; ffmpeg -framerate 13 → mp4.
