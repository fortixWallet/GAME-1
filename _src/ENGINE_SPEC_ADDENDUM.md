## 0. ГОЛОВНА ІДЕЯ ДОДАТКА

Одинадцять специфікацій **не можна виправляти вручну** — три вади повторяться в дванадцятій.
Замість цього рушій отримує **валідатор при завантаженні справи**, який **відмовляється
запускати** дані, що порушують правила. Погана форма стає **помилкою збірки**, а не смаковою
претензією на плейтесті.

Це той самий прийом, що врятував крок 1: геттер без сеттера зробив забуте присвоєння помилкою
компіляції. Тут — те саме на рівні даних.

## 1. ТРИ ВАДИ Й ЯК РУШІЙ ЇХ НЕ ПУСТИТЬ

### Вада A: варіант у бланку друкує розгадку
**Знайдено в 9 справах із 10, дослівно.** Гравець, який відкриє атестат раніше за роботу,
прочитає відповідь у списку варіантів.

**Правило рушія:** графа типу `CHOICE` **заборонена** для слотів із тегом `verdict`
(тобто тих, що несуть розв'язку). Дозволено лише `NUMBER` або `FACTS` (перетягування).

```gdscript
# core/validate.gd
const VERDICT_TYPES := [SlotType.NUMBER, SlotType.FACTS]

static func check_slots(case_id: int, slots: Array) -> Array[String]:
	var errs: Array[String] = []
	for i in slots.size():
		var s: Dictionary = slots[i]
		if s.get("tag", &"") == &"verdict" and not (s["type"] in VERDICT_TYPES):
			errs.append("case %d slot %d: verdict-графа не може бути CHOICE — розгадка в списку" % [case_id, i])
	return errs
```

### Вада B: `note`/`cite` роблять порівняння ЗА гравця
**Найгірша з трьох**, бо це пряме порушення закону V4: гра сама виконує загадку.
Приклад із перевірки: замість «the letter A stands inside the outline» текст казав
«…which means the mark is later than the workshop».

**Правило рушія:** текст факту не має містити **сполучників висновку**.
Список-стоп перевіряється при завантаженні:

```gdscript
const BANNED_IN_FACTS := [
	" means ", " therefore", " so the ", " which proves", " hence ",
	" must be ", " cannot be ", " older than", " later than", " earlier than",
	" fake", " forged", " genuine", " stolen", " authentic",
]

static func check_facts(case_id: int, facts: Dictionary) -> Array[String]:
	var errs: Array[String] = []
	for id in facts:
		var t: String = tr(facts[id]["text_key"]).to_lower()
		for bad in BANNED_IN_FACTS:
			if bad in t:
				errs.append("case %d fact %s: текст робить висновок («%s») — мусить бути лише спостереження" % [case_id, id, bad.strip_edges()])
	return errs
```

**Виняток:** порівняльні слова дозволені в **довідникових** фактах (`tag == &"books"`),
бо довідник і мусить містити правило. Заборона діє на факти, здобуті **з предмета**.

### Вада C: числова графа переписується з нотатника
**У справах 5, 9, 10.** Число, яке треба вписати, дослівно лежить у тексті факту — тобто
графа не рахується, а копіюється.

**Правило рушія:** значення `NUMBER`-графи **не має зустрічатися** в жодному факті,
доступному на момент її відкриття.

```gdscript
static func check_numbers(case_id: int, slots: Array, facts: Dictionary) -> Array[String]:
	var errs: Array[String] = []
	for i in slots.size():
		var s: Dictionary = slots[i]
		if s["type"] != SlotType.NUMBER: continue
		var ans := str(s["answer"])
		for id in facts:
			if ans in tr(facts[id]["text_key"]):
				errs.append("case %d slot %d: відповідь %s дослівно є у факті %s — це переписування, не обчислення" % [case_id, i, ans, id])
	return errs
```

**Як тоді робити числові графи чесно** (перевірено на справі 7): число **виводиться з двох
фактів арифметикою**. Гросбух дає «печатка 402 — весна 1871» і «печатка 1106 — осінь 1889»;
рік першої печатки гравець отримує екстраполяцією темпу. Ні в одному факті числа `1862` немає.

## 2. П'ЯТЬ ПРОГАЛИН РУШІЯ (без них 5 справ неімплементовні)

### 2.1. `needs_flag` — гейт по стану світу, не по факту
Потрібно справам 2 і 10. Зараз гейт уміє лише «чи є факт», а треба «чи настав вечір»,
«чи відкрито сейф», «чи лампа згасла».

```gdscript
# у SLOTS і в RULES
"needs_flag": {&"tod": &"night", &"lamp_on": false}
```
Перевірка — проти `CaseState.flags` (і `meta` для наскрізних, як `seals_set`).

### 2.2. Тест видимості якоря в `ZoneHit.pick`
**Через це годинник у справі 3 фізично неможливо відкрити.** Зона всередині кришки існує,
але поки кришка закрита, її якір недосяжний — і рушій цього не знає.

```gdscript
# зона може вимагати стану ІНШОЇ зони
"requires_state": {&"z.watch.lid": &"open"}
```
`pick()` пропускає зони, чий `requires_state` не виконано. Без цього гравець тицяє в порожнє
місце й отримує тишу.

### 2.3. `instance` — кілька екземплярів однієї зони
Потрібно справі 9: сім оголошень у газеті — це сім екземплярів однієї зони з різними даними.
Зараз довелося б писати сім зон вручну.

```gdscript
&"z.news.notice": { …, "instances": 7, "data_key": &"notice_%d" }
```
`fact_id` отримує суфікс екземпляра: `f.notice_3`.

### 2.4. Віджет пошуку в теці
Потрібно справі 3 (реєстр майстерень) і 7 (сім тек). Гравець мусить **шукати рядок**, а не
клікати по всіх. Це не текстовий пошук — це **фільтр за колонкою**: обрати «рік» → бачити
відсортоване. Інакше реєстр на 400 імен = pixel hunt.

### 2.5. Семантика `dwell` після спрацювання
Потрібно справі 11. Зараз незрозуміло: якщо факт уже здобутий, чи продовжує `observe`
накопичувати? Чи скидається `found_time`?

**Рішення:** після видачі факту `found_time` скидається в нуль, а зона переходить у стан
`&"read"`. Повторне наведення дає **той самий `say`** без нового факту — гравець може
перечитати, але нотатник не дублюється.

## 6. ЧОГО ЦЕЙ ДОДАТОК НЕ ВИРІШУЄ

Валідатор ловить **форму**, не **зміст**. Він не скаже:
- чи є в справі справжній стрибок думки (вердикти показали: **жодна не вище за «слабкий»**);
- чи хибний слід справді спокушає, а не лежить декорацією;
- чи крива складності росте (зараз плато 14–15 фактів від справи 1 до 11).

Це лишається за **гейтом правила 13**: агент-казуал проходить кліками і формулює суперечність
своїми словами. Валідатор — сито для механічних вад, гейт — для смислових.
