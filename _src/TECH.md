# TECH — як усе поєднується (Godot 4.7, GDScript)

## Принцип
Код нічого не малює. Сцена — стос мальованих текстур; код рухає/повертає/фейдить їх і рахує логіку.

## Збірка сцен
- Екран = CanvasLayer зі стосом TextureRect/Sprite2D (z-порядок = шари з карти розшарування).
- Інтерактив = TextureButton (стани звичайний/hover/натиснутий — три арт-текстури) або Area2D над спрайтом.
- Анімації: Tween позиції/повороту/альфи готових спрайтів (шухляда виїжджає, стрілка обертається навколо намальованої осі, портрет хилиться, темрява-шар проявляється альфою).
- Переходи екранів: фейд через мальовану віньєтку.
- Кнопки завжди наверх: `move_child(btns, get_child_count()-1)` (баг «зависло» з НЕЛЮДА).

## 3D «У РУКАХ»
SubViewport на мальованій рамці; GLB-частини на Node3D-півотах; обертання мишею; відкривання — tween півота (математика складання: ширина кришки = ширині тіла; нормалізація на -aabb.min; півот на задньому верхньому краї, утоплення 3–4%). Тонкі деталі — примітиви в Godot з арт-текстурою; скло/дзеркало — свій матеріал.

## Дані і стан
- Справи — JSON/Resource: {id, тип, зачіпки[3+ дороги], варіанти атестата, правильна відповідь, наслідки(вірно/невірно), тексти}. Колода — з CONTENT.md.
- GameState (autoload): день, лічильники (Чесність/Цікавість/Борг/печатки), відкриті зачіпки, стани секретів кабінету, інвентар (шпилька, ключик…). Сейв = JSON у user://, автозбереження щовечора + при закритті справи.
- Атестат: варіанти-картки будуються ТІЛЬКИ з відкритих зачіпок (правило Шерлока №1).
- Драбина підказок: таймер тиші + лічильник хибних спроб → тригер діегетичної події (кіт/лист/«читачка»). Логіку не видно гравцю.
- Кінцівка = функція лічильників (пороги в JSON, балансуються плейтестами).

## Граблі (вшиті, не обговорюються)
Явні типи замість Variant-інференсу (warnings=errors) · битий асет заміняти НОВИМ іменем · `.gdignore` на `_src` · ui_token-покоління проти async-гонок · JPEG-під-.png нормалізувати PIL до імпорту · GLB тільки через gltf-transform `--compress false`.

## Верифікація (кожен білд, без машини Віктора)
```
G=/tmp/Godot_v4.7-stable_linux.x86_64        # downloads.godotengine.org ?version=4.7&flavor=stable&slug=linux.x86_64.zip
$G --headless --path . --import               # імпорт + компіляція
$G --headless --path . --script res://autotest.gd   # сценарії: агент проходить кожну справу (t_press/t_state хуки)
xvfb-run -a $G --path . --rendering-driver opengl3 & sleep 8 && import -window root shot.png   # скріншот — дивитись ОЧИМА
xdotool mousemove X Y click 1                 # реальні кліки по всіх зонах (синтетика пропускає перекриття вводу)
```
Економіка (борг/гонорари/пороги кінцівок) — Monte-Carlo у Python ДО імплементації.
