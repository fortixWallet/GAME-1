# Зони садяться по виміряному, не на око

## Процедура
1. Сітка часток на плиту:
```python
for f in [i/20 for i in range(1,20)]:
    d.line([(W*f,0),(W*f,H)]); d.line([(0,H*f),(W,H*f)])  # підписати 0.1..0.9
```
   Read сітку → назви точні частки (u, half) прямо з неї.
2. Або детекція: латунь `r-b>45 & r>115`, сукно `g>r+4 & g-r<45`, темне
   `sum<210`. Центр шукай ПРИВ'ЯЗКОЮ до очікуваного місця (±38 px), не
   глобальною кластеризацією — вона тягне сусідні деталі (завіси!).
3. Зона в data: `"u": Vector2(цх, цy)` частками ПЛИТИ (не екрана), `half` —
   теж частками. pick_2d бере НАЙМЕНШУ зону під курсором — велика зона-фон
   («вся річ») не перекриє дрібних.
4. Екранна точка для пілота: `px = frame.x + u.x*frame.w` (frame: плита вписана
   ih=H*0.94, iw≤W*0.72, по центру).
5. Перевір кліком пілота, що зона ловиться, і `furnprobe` (bad_frame=0).

## Закони
- Кожна видима гравцеві деталь = зона з відповіддю на КОЖЕН інструмент
  (око/лупа/лампа мінімум say; факти — лише де щось СПРАВДІ видно).
- Що сказано в say — те МУСИТЬ бути видно на плиті (закон Віктора 02.08).
