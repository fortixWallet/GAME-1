# Стан предмета — генерацією, камера — недоторканна (правило 19 CLAUDE.md)

Заміряно 31.07: референс тримає камеру ІДЕАЛЬНО (0.48–0.64, dx=dy=0), поки промпт
не згадує камеру. Слова "closer / macro / move the camera / zoom" = нова зйомка
(0.012) = викинутий кадр і втрачений день.

## Процедура
1. Промпт будуй так: "The reference photograph shows … Reproduce THIS EXACT
   PHOTOGRAPH with ONE change: <зміна>. Everything else stays exactly as in the
   reference. Photorealistic, same lamplight. Absolutely no readable text"
   (виняток на текст — лише свідомий, як тавро GRUBER).
2. ЗАБОРОНЕНІ слова в промпті: closer, macro, zoom, move the camera, close-up,
   camera. Наближення НЕ генерується — тільки кроп або HD-майстер.
3. Генеруй 2 спроби: `tools/gen_state.py <ref> <out> "<prompt>"` (ключі: source
   .keys.env; python: $SCRATCH/gvenv/bin/python3).
4. Кожну спробу МІРЯЙ до вставки: `tools/check_frames.py` або вручну фазова
   кореляція проти якоря групи (box_closed для скриньки). Збіг < 0.3 → викинути.
5. Дрібні деталі, які модель мусить показати ЧИТАБЕЛЬНО (сліди, тріщини) —
   описуй перебільшено ("clearly readable, make the difference obvious").
6. Після заміни кадру: перерізати залежні спрайти (виміряти центри ПРИВ'ЯЗКОЮ
   до старих, не кластеризацією — вона хапає сусідню латунь), оновити SPOTS,
   `godot --headless --import`, тоді гейт `--c2`.

## Заборонено
- Клеїти чужі пікселі латками поверх кадру (шви видно; двічі оплачено).
- Малювати видимий піксель кодом (правило 1). Написи — шрифтом або в генерації.
