# Гейт Bureau: tools/gate.py

Все з кореня гри: `cd /Users/skydrows/Documents/Game/Bureau`.

| Режим | Команда | Коли |
|---|---|---|
| fast | `.venv/bin/python3 tools/gate.py` | 16 швидких сенсорів, перед комітом |
| full | `.venv/bin/python3 tools/gate.py --full` | + повільні (flip/world/frames/book_box, відео) |
| neg | `.venv/bin/python3 tools/gate.py --neg` | негативні самотести сенсорів |

Точковий сенсор після правки шматка: `.venv/bin/python3 tools/check_XXX.py`
(scenes → check_scenes; зони → check_zones_alive + check_ergo; підпис →
check_sign; кадри → check_frames). НЕ ганяти повний гейт по колу — він раз,
перед комітом (пам'ять game3-no-full-gate-loops).

## Закони
- НІКОЛИ `pkill -9 -f godot` (уб'є гру Віктора). Лише `pkill -9 -f "godot.*bridge"`.
- Два гейти паралельно б'ються за GPU і валять тести випадково. Один за раз.
- Гейт червоний → `git commit` НЕ виконується. Крапка.
- Правило 17: сенсор спершу друкує СКІЛЬКИ переглянув; нуль знахідок при
  нулі переглянутого = поломка сенсора. Новий сенсор мусить мати --self-test
  (правило 27), і його негатив мусить ПАДАТИ на підсунутій ваді.
- Сенсор звіряє ЗВ'ЯЗКИ контракту, не наявність частин (урок check_sign 22.08).
- Головний тест — не гейт, а казуал кліками (правило 13); гейт лише охоронець
  регресій.
