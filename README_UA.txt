BUREAU OF ATTRIBUTION — Справа 1 «Срібний келих»
Проєкт Godot 4.7 (base language: English; UA — локалізація пізніше)

ЯК ЗАПУСТИТИ
1. Відкрий Godot 4.7 → Import → вибери цю папку (файл project.godot) → Open.
2. Перший імпорт арту займе ~10–20 с (це нормально, Godot стискає текстури).
3. Натисни Play (F5).

КЕРУВАННЯ (справжня взаємодія, не «клік = наступний екран»):
- Стіл: наведи на річ — вона підсвічується; клікни КЕЛИХ — береш у руки.
- В руках: тягни мишею — келих крутиться у 3D; клікни НОГУ келиха — лупа з клеймами.
- Лупа → «Consult the mark catalogue»: у довіднику клікни герб-ЗБІГ (☧ монограма).
- Тека (папери) → газета: «ROBBERY AT ST. ONUPHRIUS' SACRISTY».
- Атестат: під кожною графою — варіанти, клікаєш потрібний. Правильно:
  ORIGIN = Vienna, Hoffmann workshop | AUTHENTICITY = original | SPECIAL NOTE = STOLEN.
  Коли всі три заповнені — клік по медальйону внизу = печатка → «CASE CLOSED».
- Помилка НЕ карає: можна перевибрати відповідь і запечатати знову.

ПРИМІТКА ПРО ЯКІСТЬ
Арт full-res (стіл 5504px). Для гри Godot стискає його при імпорті —
на екрані виглядає ідентично, але VRAM/розмір білда будуть меншими.

СТРУКТУРА
project.godot, main.tscn, main.gd — код (лише рухає готовий арт).
art/ — усі мальовані шари (png). audio/ — 7 SFX + ambient. fonts/ — Playfair + Marck.
models/goblet.glb — 3D срібний келих (текстури вшиті).
